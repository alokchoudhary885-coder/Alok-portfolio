## 🚀 Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/alokchoudhary885-coder/Alok-portfolio.git
cd Alok-portfolio
```

### 2. Install Dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Run Local Server
```bash
npm run dev
```

### 4. Build Production Bundle
```bash
npm run build
```
